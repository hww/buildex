# 3. Временные диаграммы

Символы волны: `p` — такт, `0`/`1` — уровни, `=` — шина с подписью из `data`, `x` — неопределённо,
`z` — Hi-Z, `.` — продолжение предыдущего. Красные стрелки — `arrows` с подписью; тик можно задавать
дробным (`1.5` — середина такта).
